# The demo video (source)

The finished video is `demo/airlock-demo.mp4` (version 5, 1:31). This folder is how it was made.

The demo video is a HyperFrames composition. `index.html` is generated by `build/build_v5.py` from `build/v5_template.html`. Version 5 puts the iMessage bubbles on the correct sides (sent on the right, received on the left) and times every caption and box on the explainer slides to the exact word being spoken, using the word-level transcripts in `narration-words/`. Versions 3 and 4 are kept in `archive/` (and as their own rendered files). It joins a title, an animated iMessage bubble that zooms into the website, an animated explainer of how Airlock checks a contract, the narrated walkthrough, the rules, and an outro.

**Narration.** `narration.json` holds the script. `narrate.mts` turns each line into an mp3 with ElevenLabs text-to-speech, the same voice as the website (run from `voice/`: `npx tsx --env-file=../.env ../video/narrate.mts <folder>`). The key comes from `.env` and is never printed.

**Not in this repository.** The screen recordings (the website, an iPhone, and the walkthrough), the music and the rendered video are large, and the iPhone recording shows a real phone's messages. To rebuild, put your own recordings in `assets/media/` (`site.mp4`, `sitezoom.mp4`, `walk.mp4`), the narration mp3s in `assets/narration/`, and a music track in `assets/music/`. Copy `narration-words/*.words.json` next to the narration mp3s in `assets/narration/`. The offsets inside the recordings are set in `build/build_v5.py`. Then run `python3 build/build_v5.py`, `npx hyperframes check` and `npx hyperframes render`.
