# The demo video (source)

The demo video is a HyperFrames composition. `index.html` is generated by `build/build_v4.py` from `build/v4_template.html` (version 4: tighter pacing, a grey Airlock reply in the iMessage scene, redrawn arrows and boxes). Version 3, the first narrated cut, is kept in `archive/v3/` and as its own rendered file. It joins a title, an animated iMessage bubble that zooms into the website, an animated explainer of how Airlock checks a contract, the narrated walkthrough, the rules, and an outro.

**Narration.** `narration.json` holds the script. `narrate.mts` turns each line into an mp3 with ElevenLabs text-to-speech, the same voice as the website (run from `voice/`: `npx tsx --env-file=../.env ../video/narrate.mts <folder>`). The key comes from `.env` and is never printed.

**Not in this repository.** The screen recordings (the website, an iPhone, and the walkthrough), the music and the rendered video are large, and the iPhone recording shows a real phone's messages. To rebuild, put your own recordings in `assets/media/` (`site.mp4`, `sitezoom.mp4`, `walk.mp4`), the narration mp3s in `assets/narration/`, and a music track in `assets/music/`. The offsets inside the recordings are set in `build/build_v4.py`. Then run `python3 build/build_v4.py`, `npx hyperframes check` and `npx hyperframes render`.
